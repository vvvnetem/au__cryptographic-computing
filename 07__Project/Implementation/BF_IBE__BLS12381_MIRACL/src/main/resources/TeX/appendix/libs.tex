\section{Libraries for Pairing-based Cryptography}
\label{sec:apx.libpbc}

For our project we choosed to use \textit{Java} programming language,
hence we considered libraries first whose functions can be called
trough Java first. On the otherhand we also note that in case the overall
performance is also a desired property of the BF-IBE system libraries from
\textit{relic-toolkit}\cite{relic-toolkit} can be called trough wrappers.
