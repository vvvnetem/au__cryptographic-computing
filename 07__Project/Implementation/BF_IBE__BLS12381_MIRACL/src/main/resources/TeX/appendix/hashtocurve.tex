\section{Hash-to-curve parameters for curve BLS12-381}
\label{sec:apx.hashtocurve}

In \textit{Table \ref{tab:bls12381hashg1g2}} encoding type denotes either random oracle (\lstinline|hash_to_curve|) or nonuniform (\lstinline|encode_to_curve|).
$E$ denotes the target elliptic curve over a field $\mathbb{F}$, $p$ the characteristic of the field $\mathbb{F}$, $m$ the extension degree of the field $\mathbb{F}$.

$k$, the target security level of the suite in bits. $L$ the length parameter for \lstinline|hash_to_field|, \lstinline|expand_message| denotes one of the variants specified in Section 5.3 of \cite{ecc.hashing} plus any parameters required for the specified variant (for example, $H$, the underlying hash function).$f$, a mapping function. $h_{eff}$ is the scalar parameter for \lstinline|clear_cofactor|. In addition the mapping $f$ require additional parameters $Z$, $M$, \lstinline|rational_map|, $E'$, and \lstinline|iso_map|. \cite{ecc.hashing}
